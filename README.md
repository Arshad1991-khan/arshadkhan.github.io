# Dr Arshad Khan — Academic Website

GitHub Pages-ready personal academic website.

## Before publishing
1. Add your profile photo to `images/profile.jpg` and change the avatar in `index.html` if desired.
2. Add real URLs for Google Scholar, ORCID, LinkedIn and GitHub.
3. Add your professional email.
4. Replace the selected-publication summaries with your verified complete publication list, exact authors, DOI and publisher links.
5. Add `cv.pdf` if you want a downloadable CV.
6. Review all claims and dates before making the site public.

## GitHub Pages
Create a public repository named `YOURUSERNAME.github.io`, upload the files, then go to Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
